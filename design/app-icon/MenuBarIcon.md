# メニューバー用アイコン

アプリアイコンの3層のキャッシュスラブを、透明背景に黒一色で表した専用マークです。
メニューバーでは画像の色ではなくアルファを使用し、macOS が外観に応じた色で表示します。

- `MenuBarIcon-source.png`: 生成した高解像度の透過素材。
- `../../Zen-ith/Assets.xcassets/MenuBarIcon.imageset/`: 表示サイズ18pt用の18px／36px画像。
- アセットの `template-rendering-intent` と SwiftUI の `.renderingMode(.template)` を設定済み。
- 通常のアプリアイコンと、警告・スキャン中の状態バッジは従来どおりです。

## 制作方法

内蔵 ImageGen ツールで既存の `Zen-ith-1024.png` を参照し、次の指示で制作しました。

> ネイビーの背景タイル、色、陰影、グラデーション、立体表現を取り除き、
> 元の3層の斜めのキャッシュスラブを黒一色の独立したシルエットとして残す。
> 18pxの高さでも3層が分かるよう透明な間隔を広く取り、背景は完全に透明にする。
> 輪郭は滑らかにし、文字や装飾を加えない。

元画像から `sips -z 18 18`／`sips -z 36 36` で表示用PNGを書き出しています。
