# Zen-ith app icon — Unstack

Approved concept A: three mint cache slabs on a midnight navy rounded tile.
The tile's exterior is transparent; the artwork includes its own corner shape and padding.

- `Zen-ith-source.png`: original generated artwork.
- `Zen-ith-1024.png`: 1024 × 1024 RGBA master for macOS.
- `Zen-ith.icns`: macOS icon compiled by Xcode's asset catalog compiler.
- `Zen-ith.iconset/`: ten PNG representations, 16–1024 pixels.
- `../../Zen-ith/Assets.xcassets/AppIcon.appiconset/`: installed Xcode asset catalog.

Re-export with `python3 scripts/export_app_icon.py` from the repository root.
Requires macOS, `sips`, Python 3, and Xcode command line tools.
This asset is for the application icon. The menu bar template symbol is separate.
